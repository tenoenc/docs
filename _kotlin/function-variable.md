### 함수와 변수

#### Hello, World!

```kotlin
fun main(args: Array<String>) {
    println("Hello, world!")
}
```

이 코드에서 코틀린의 문법이나 특성을 확인할 수 있다.
- 코틀린 프로그래밍은 수많은 `fun`을 만드는 재미있는(fun) 일이다.
- 파라미터 이름 뒤에 그 파라미터의 타입을 쓴다. 변수를 선언할 때에도 마찬가지이다.
- 함수를 최상위 수준에 정의할 수 있다.
- 배열도 일반적인 클래스와 같다.
- `System.out.println` 대신에 `println`이라고 쓴다. 코틀린 표준 라이브러리는 여러 가지 표준 자바 라이브러리 함수를 간결하게 사용할 수 있게 감싼 래퍼(wrapper)를 제공한다.
- 줄 끝에 세미콜론을 붙이지 않아도 된다.

#### 함수

```kotlin
fun max(a: Int, b: Int): Int {
    return if (a > b) a else b
}
```

함수 선언은 `fun` 키워드로 시작한다. `fun` 다음에는 함수 이름이 오고, 함수 이름 뒤에는 괄호 안에 파라미터 목록이 온다. 함수의 반환 타입은 파라미터 목록의 닫는 괄호 다음에 오는데, 괄호와 반환 타입 사이를 `:`으로 구분해야 한다.

> 코틀린의 `if`는 statement(문)가 아니고 결과를 만드는 expression(식)이다. 자바에서는 모든 제어 구조가 statement인 반면 코틀린에서는 루프를 제외한 대부분의 제어 구조가 expression이다.
> 반면, 대입문은 자바에서는 expression이었으나 코틀린에서는 statement가 됐다. 그로 인해 자바와 달리 대입식과 비교식을 잘못 바꿔 써서 버그가 생기는 경우가 없다.
{: .block-tip }

##### 식이 본문인 함수

앞의 `max()` 함수를 더 간결하게 표현할 수 있다.

```kotlin
fun max(a: Int, b: Int): Int = if (a > b) a else b
```

본문이 중괄호롤 둘러싸인 함수를 "블록이 본문인 함수"라 부르고, 등호와 식으로 이뤄진 함수를 "식이 본문인 함수"라고 부른다. 코틀린에서는 식이 본문인 함수가 자주 쓰인다.

**블록이 본문인 함수는 컴파일러가 타입 추론을 지원하지 않는다**

사실 위 함수를 더 간략하게 할 수 있다.

```kotlin
fun max(a: Int, b: Int) = if (a > b) a else b
```

코틀린은 정적 타입 지정 언어지만, 식의 타입 추론을 지원하기 때문에 반환 타입을 생략해도 문제 없다. 반면에 블록이 본문인 함수의 경우에는 반환 타입을 생략할 수 없다. 코틀린이 이렇게 설계한 의도에는 코틀린의 철학 중 **실용성과 관련**이 있다. 실전 프로그래밍에는 아주 긴 함수에 `return`문이 여럿 들어있는 경우가 있다. 이 때 반환 타입을 명시하고 `return`을 반드시 사용한다면 함수가 어떤 타입의 값을 반환하는지 더 쉽게 알아볼 수 있다.

#### 변수

```kotlin
val question = "삶, 우주, 그리고 모든 것에 대한 궁극적인 질문"
val answer: Int = 42
```

변수 선언은 키워드로 시작한다. 변수 이름 뒤에 타입을 명시하거나 생략하게 허용한다. 변수는 그 자체로 expression이기 때문에 타입을 생략해도 문제 없다.

**변수 타입을 반드시 명시해야 하는 경우**

만약 초기화 식을 사용하지 않고 변수를 선언하려면 변수 타입을 반드시 명시해야 한다.

```kotlin
val answer: Int
answer = 42
```

초기화 식이 없다면 변수에 저장될 값에 대해 아무 정보가 없기 때문에 컴파일러가 타입을 추론할 수 없다.

##### 변경 가능한 변수와 변경 불가능한 변수

- `val` (value): 변경 불가능한(immutable) 참조를 저장하는 변수다. `val`로 선언된 변수는 일단 초기화하고 나면 재대입이 불가능하다. 자바로 치면 `final` 변수에 해당한다.
- `var` (variable): 변경 가능한(mutable) 참조다. 이런 변수의 값을 바뀔 수 있다. 자바의 일반적인 변수에 해당한다.

> 변경 불가능한 참조와 변경 불가능한 객체(**불변성**)를 부수 효과가 없는 함수(**일급 시민 함수 + 부수 효과 없음**)와 조합해 사용하면 코드가 함수형 코드에 가까워진다. 

#### 더 쉽게 문자열 형식 지정 (문자열 템플릿)

```kotlin
fun main(args: Array<String>) {
    val name = if (args.size > 0) args[0] else "Kotlin"
    println("Hello, $name")
}
```

이 예제는 문자열 템플릿이라는 기능을 보여준다. 문자열 템플릿은 자바의 문자열 접합 연산과 동일한 기능을 하지만 좀 더 간결하며, 자바 문자열 접합 연산을 사용한 식과 마찬가지로 효율적이다.

> `$` 문자를 문자열에 넣고 싶은 경우에는 `\`를 사용해 이스케이프(escape)시켜야 한다.
{: .block-tip }

**복잡한 식의 경우**

문자열 템플릿 안에 사용할 수 있는 대상은 간단한 변수 이름만으로 한정되지 않는다. 복잡한 식도 중괄호(`{}`)로 둘러싸서 문자열 템플릿 안에 넣을 수 있다.

```kotlin
println("Hello, ${args[0]}")
```

중괄호로 둘러싼 식 안에서 큰 따옴표를 사용할 수도 있다. 다른 언어처럼 큰 따옴표와 작은 따옴표를 구분해서 사용할 필요 없다.

```kotlin
println("Hello, ${if (args.size > 0) args[0] else "Kotlin"}")
```
