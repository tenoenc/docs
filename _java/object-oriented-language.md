### 객체지향언어

#### 객체지향언어의 출현

컴퓨터가 미사일 발사실험과 같은 모의실험을 목적으로 사용되던 시기, 과학자들은 모의실험을 위해 실제 세계와 유사한 가상 세계를 컴퓨터에서 구현하고자 노력하였으며 여기서 객체지향이론이 탄생했다. 객체지향의 기본 개념은 "실제 세계는 사물로 이루어져 있으며, 발생하는 모든 사건은 사물과의 상호작용에 의해 일어난다"라는 것이다. 객체지향이론은 상속, 캡슐화, 추상화 개념을 바탕으로 점차 발전하였으며, 1960년대 중반 시뮬라라는 최초의 객체지향언어가 탄생했다. 당시에는 코볼이나 포트란 같은 절차지향언어가 주를 이루었으며, 객체지향언어에 대한 관심이 적었다. 그러나 프로그램의 규모가 점점 커지고 사용자들의 요구가 빠르게 변화화면서 대안으로 객체지향언어를 이용한 개발방법론이 점점 입지를 넓혀 갔다. 자바가 1995년에 발표되고 1990년대 말에 인터넷의 발전과 함께 객체지향언어는 프로그래밍언어의 주류로 자리 잡았다.

#### 객체지향언어의 특징

* **재사용성 높음**
* **유지보수성 용이**: 코드간의 관계를 이용해서 쉽게 코드 변경
* **신뢰성 높음**: 제어자와 메서드로 데이터를 보호하고, 코드의 중복을 제거하여 불일치로 인한 오동작을 방지

#### 클래스와 객체

클래스는 설계도이고, 객체는 설계도로 만든 실체이다. 클래스를 하나 만들어두면 얼마든지 객체를 생성할 수 있으며, 이 객체는 힙 메모리 공간에 위치하게 된다. 보통 인스턴스는 객체와 비슷한 의미로 사용하는데 엄밀히 구분하면 인스턴스는 클래스와의 관계를 나타낼 때 사용된다. 예를 들어, `B`는 클래스 `A`의 객체다 라고 하지 않고 `B`는 클래스 `A`의 인스턴스이다.


#### 클래스의 구성요소

클래스는 속성과 기능으로 정의된다. 속성은 객체가 무엇을 가지고 있는지를, 기능은 무엇을 할 수 있는지를 나타낸다. 보통 속성은 멤버변수라고 하고, 기능은 메서드라고 한다. 

#### 인스턴스의 생성과 사용

```java
class Tv {
    String color;
    boolean power;
    int channel;

    void poser() { power = !power; }
    void channelUp() { ++channel; }
    void channelDown() { --channel; }
}

class TvTest {
    public static void main(String[] args) {
        Tv t;
        t = new Tv();
        t.channel = 7;
        t.channelDown();
        System.out.println("현재 채널은 " + t.channel + " 입니다.");
    }
}
```

1. `Tv` 클래스 타입의 참조변수 `t`를 선언한다. 메모리에 참조변수 `t`를 위한 공간이 마련된다.
2. `Tv` 클래스의 인스턴스가 힙 메모리의 빈 공간에 생성된다.
